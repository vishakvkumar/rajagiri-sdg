# Rajagiri SDG page demo

A working demo of the proposed Rajagiri SDG page. Everything is on one page:

- About Rajagiri SDG text
- 17 SDG tiles, one per UN Sustainable Development Goal
- Clicking a tile opens that goal's PDF on the same page
- "Back to all goals" (or the browser back button) returns to the tiles
- RAINBOW section with its related documents

Each goal also has its own link, for example `#sdg3`.

## Files

- `index.html` – the demo page
- `pdfs/` – placeholder PDFs (`sdg1.pdf` … `sdg17.pdf`); replace them with the real reports
- `Rajagiri-SDG-Page-Content.docx` – page content for the web team, with links to the 17 PDFs

Live demo (after GitHub Pages is switched on): https://vishakvkumar.github.io/rajagiri-sdg/
